# PokeIO v2.0 — Integration Plan (System-1 core ↔ the current harness)

How the new brain (Fable-scoped v1 = System-1 core) plugs into what exists. **Additive, not a destructive
rewrite:** the new RL loop is built ALONGSIDE the NEAT loop (which stays as a reference/baseline until the
gate), reusing the emulator fleet, perception, archive, and eval harness.

## What's REUSED unchanged
- **Emulator fleet — `pokeio/emu/fleet.py::AsyncFleet`** (the furnace). The step/obs/action boundary the RL
  core plugs into, verbatim:
  - `reset_all(restore) -> obs` / `reset_all_begin/end` — episode start (+ Go-Explore restore).
  - `submit_actions(idx, buttons, gaze_dx, gaze_dy, obs_idx)` — the action sink.
  - `_batched_obs() -> {obs}` — the batched observation source.
  This is already GPU-friendly (batched obs); the RL core replaces only what sits *between* obs and action.
- **Perception front-end — `FovealEncoder`** (= occipital). Produces the obs vector the actor-critic reads.
  Task #33 verifies motion/fovea actually reach the gradient; no rebuild.
- **Adaptive cadence** (= premotor) — reuse the commit-gate/dwell for the actor's action timing (#34).
- **Eval harness — `pokeio/eval/`** (metrics/controls/harness) — extended into the evaluation spine (#29).
- **Dashboard — `pokeio/dash/`** — the wall + STOP button + the "what the AI sees" panel, unchanged.
- **MF modules — `pokeio/reward/preference.py`, `llm/annotate.py`, `manifest/generate.py`** — the LLM's v1
  job (offline frozen reward, #37), used *offline* only.

## What's REPLACED
- **The policy learner.** `pokeio/evo/{genome,forward,ops}.py` + `population_forward_sparse → _split_head →
  argmax` (loop.py) → a **gradient actor-critic** (new `pokeio/brain/actor_critic.py`, torch nn: obs →
  action logits + value). NEAT is retired *as the policy learner* (its population/QD/ERL ideas move to the
  deferred evolutionary outer loop #41).
- **The training loop.** `pokeio/train/loop.py` (the neuroevolution generation loop) → a new
  `pokeio/train/brain_loop.py` (an RL loop: collect rollouts via the fleet → compute advantages/returns →
  gradient update → periodic eval). The NEAT loop stays runnable for baseline comparison until the gate.

## What's MODIFIED
- **Go-Explore archive — `pokeio/reward/goexplore.py`** (= hippocampus, #31). Today `CellEntry.state` is a
  ~47 ms PyBoy **save_state blob**. Change to store a **trajectory** (a start-state reference + the
  deterministic action sequence that reaches the cell) → exact replay (determinism), kills the capture burn,
  lifts the RAM/state memory wall. Add the **backward-robustification sampler**: yield (start = a point
  progressively earlier along a deep trajectory, goal = the cell) training episodes.
- **Reward — new `pokeio/brain/reward.py`** (#30). Dense, teleport-decoupled (restore doesn't hand reward
  the policy didn't earn), never fed to the agent as an input, validated by the from-boot metric (#28).
  Absorbs the good parts of `pokeio/reward/*` (miner as a *progress* source, NOT an obs input) + permanent
  coupling instrumentation (obs→action MI, RAM-tap ablation Δ, no-restore selection eval).

## New module layout
```
pokeio/brain/
  actor_critic.py   # the policy+value net (basal ganglia); reads the FovealEncoder obs
  rl_loop.py        # PPO/IMPALA-style: rollouts -> GAE -> update; GPU-batched forward on ~1 P100
  replay.py         # trajectory store + backward-robustification sampler (hippocampus)
  reward.py         # coupled/dense/decoupled reward + coupling instrumentation
  neuromod.py       # inline self-calibrating scalars (NE/ACh/5-HT), #40 — a few functions, not a subsystem
pokeio/train/brain_loop.py   # the new training entrypoint (parallels train/loop.py)
pokeio/eval/spine.py         # the evaluation spine (#29) on top of the CR harness
pokeio/reward/from_boot.py   # the from-boot progress metric (#28)
```

## Integration seams (interfaces)
1. **obs:** `AsyncFleet._batched_obs()` → `FovealEncoder`-shaped vector → `actor_critic.forward(obs) ->
   (logits, value)`.
2. **action:** sample from logits (+ AC cadence gate #34, + gaze from the reflex/learned blend) →
   `submit_actions(...)`.
3. **reward:** per-step, `reward.py` reads env RAM/state (NOT into the obs) → scalar for the critic.
4. **replay:** `replay.py` samples backward-robustification episodes → `reset_all(restore=start)` →
   goal-conditioned rollout.
5. **eval:** `spine.py` runs from-boot gauntlets (#28 metric) with IQM+CIs + controls → the gate #35.

## Compute layout (Pascal honesty)
- **Card 1 = training** (actor-critic + GPU-batched forward + any small critic/aux nets). ~1 P100.
- **Card 0 = LLM** (offline frozen-reward distillation only, #37; deferred). Do NOT put a live LLM on the
  training path.
- We are **CPU-bound on frame-stepping**; GPU-side encode + pipelined forward are near-free upside but do
  NOT move the throughput ceiling (that's the emulator, #36).

## Migration / safety
- Build `pokeio/brain/` + `train/brain_loop.py` as NEW files; leave the NEAT loop intact as the baseline.
- Each seam is unit-tested against the real fleet (a 1-2 env smoke) before the full loop.
- The gate (#35) compares the RL core's from-boot competence to the NEAT baseline's ~4.4% — apples-to-apples
  on the same fleet + metric.
- Nothing is rewarded/evolved against the from-boot metric until it reads materially nonzero (#28 first).
